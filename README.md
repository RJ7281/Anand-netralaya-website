The official front-end web repository for **Anand Netralaya Eye Care Hospital** (Virar West, Maharashtra), founded and led by **Dr. Anand Rout** (MBBS, DOMS, DNB, FICO UK). 

This platform delivers a high-performance, mobile-first experience designed to streamline patient onboarding, present specialized ophthalmic clinical procedures, and provide seamless appointment booking.

---

## 🌟 Key Features

- **Modern Glassmorphism Design System:** Tailored medical-grade theme with smooth gradients, responsive container layouts, and accessibility-first typography (`Plus Jakarta Sans`).
- **7 Specialty Clinics Hub:** Dedicated sections showcasing advanced eye care subspecialties:
  1. Cataract Clinic
  2. Retina & Cornea Clinic
  3. Glaucoma Clinic
  4. LASIK & Spectacle Removal
  5. Pediatric & Squint Evaluation
  6. Phacoemulsification Surgery
  7. Dry & Lazy Eye Evaluation
- **Interactive Patient Visit Guide:** Step-by-step visual timeline outlining what patients should expect upon arrival at the hospital.
- **Infinite Testimonial Marquee:** Smooth, infinite auto-scrolling patient review carousel with hover-to-pause controls.
- **Dedicated Appointment Booking (`appointment.html`):** Interactive booking interface with specialty routing, date pickers, and pre-consultation guidelines.
- **Live Location & Contact Suite:** Embedded interactive Google Maps (`Kharodi Naka, Bolinj Road`), 1-tap phone dialers, and direct WhatsApp integration.
- **Frequently Asked Questions (FAQ):** Accordion-style expandable FAQ covering pupil dilation, consulting hours, insurance assistance, and visit preparations.

---

## 🛠️ Technology Stack

- **HTML5:** Semantic markup structure optimized for accessibility and SEO.
- **Tailwind CSS (CDN):** Utility-first styling framework with custom glassmorphism effects, flexbox/grid architecture, and responsive breakpoints.
- **Vanilla JavaScript (ES6+):** Lightweight script for mobile drawer toggles, FAQ accordions, metric counter animations, and infinite marquee interactions.
- **Lucide Icons:** Modern vector icons for UI navigation and clinical categories.
